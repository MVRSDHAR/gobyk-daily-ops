# Gobyk Daily Ops — Starter App

This is a working starting point: real login, real Supabase connection,
one working page pulling real data through Row Level Security.

It is NOT the complete app yet — it's the foundation to build the rest
of the 9 screens onto (entry form, admin dashboard, guest access, bulk
fill, etc.), each of which was already designed and approved as HTML
mockups earlier in this project.

See the step-by-step guide provided in chat for exactly how to:
1. Set up Supabase (run supabase_setup.sql)
2. Push this to GitHub
3. Deploy to Vercel
4. Create your first real login and test it end to end
